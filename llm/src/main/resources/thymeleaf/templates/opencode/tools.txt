TOOLS. The shell runs any command that only reads: pipes, `&&`, `cd`, `ls`, `find`, `grep`, `head`, `sed -n` and every read-only git command are fine. Refused are commands that change the repository or this checkout (git commit, checkout, reset, stash, merge, rebase, apply, config; rm, mv, cp, touch, sed -i), builds (mvn, gradle, npm) and process or container control (kill, docker): the commit's own build and tests run in this same checkout while you review. Write scratch files only under /tmp. Files outside the repository, such as dependency sources in the local Maven repository, can be read.
