TOOLS. The shell runs exactly one read-only git command per call (show, diff, log, grep, ls-tree, blame, cat-file, rev-list and the like) with no pipes, `&&`, `;`, `cd` or redirects: anything else is refused. List files with glob, search with grep or `git grep`, read a file with read (it takes a line range) and an older version with `git show <sha>:<path>`. Only the repository can be read: dependency jars and other files outside it are out of reach, so do not look for them.
