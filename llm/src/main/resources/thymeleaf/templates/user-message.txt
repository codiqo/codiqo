Per STEP 1a in the system prompt, you provide ONLY the semantic labels: per-block `blockKinds` (`"inPlace"` vs `"trueModify"`) and the `cosmeticAdded` / `cosmeticDeleted` exception lists.

Every effective `-` / `+` line in `fileChanges[*].diff` is annotated `-<old-file line>|B<n>|content` / `+<new-file line>|B<n>|content` — its authoritative line number and change-block id. **Copy block ids and line numbers from these tags exactly** — never count lines or derive anything from hunk headers.
